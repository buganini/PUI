Unreleased (changes since 1.3):
    API changes:
        * Remove Web base_url, --base-url and WEB_BASE_URL. Browser resources, WebSockets and authentication redirects now use page-relative URLs; mount_path remains the independent upstream routing setting

    Web server:
        * Add start(passthru=True) and --passthru for a single in-process session without supervisor workers. Reconnect automatically and omit the supervisor's Resume/Renew/Logout controls
        * Add Web-only PUI.web.Application.stop() and wait_started(timeout=None). stop() blocks until server connections, workers and tunnels are cleaned up and must run outside the server event-loop thread. wait_started() returns the actual bound TCP URL or Unix socket path, including an automatically assigned port, and propagates startup failures
        * Add managed reverse tunnels through start(wstunnel={...}). Require url/token; accept optional bind for a relay-side TCP listener or Unix socket and optional wstunnel for the executable path (default: PATH lookup). Default relay bind is tcp://127.0.0.1:0; verify TLS certificates and stop the tunnel with the server
        * Fix login when a stale cookie from another path shadows the current session; reject conflicting valid session identities

    Widgets and layout:
        * Add TextEdit across PySide6, wx, Tkinter, Flet, Textual, Web and Pyodide, with committed/draft bindings, input/change events, readonly/wrap options and backend-supported placeholders
        * Add Web/Pyodide Html(text, selectable=False) for trusted HTML fragments, with scoped Shadow DOM styles, inherited PUI styles and retained content updates. Markdown remains unimplemented on these backends
        * Propagate descendant expansion demand through containers at priority 2; use priorities 3/4/5 for container axes, shrinkable controls and explicit positive weights. Respect visibility and explicit dimension boundaries without propagating descendant weights
        * Allocate Grid columns and rows by expansion priority on PySide6, wx, Tkinter, Web/Pyodide and Textual. Include every covered track in span demand, apply child weights on both axes and recompute on visibility/placement changes. Automatic columns no longer force equal widths
        * Keep Web/Pyodide Grid tracks with equal expansion weights at their own content sizes before sharing extra space. Keep lower-priority label columns compact beside spanning toolbars/nested sections, and preserve outer Spacer allocation. Vertically center Grid label text while retaining left alignment and cell/span filling
        * Make Buttons fit their content on PySide6, wx, Tkinter, Flet and Textual, retaining theme padding and explicit sizing. Fit and remeasure Textual clickable Labels when their text changes
        * Restore PySide6 Tab page default padding while preserving explicit overrides

    Examples, documentation and builds:
        * Add PUI.examples.dual_backend: PySide6 on the main thread and Web on a background thread share text, count and a curve cursor expressed as a sample index. Use public Web startup/shutdown APIs and optional wstunnel CLI settings; shared State thread safety is unchanged
        * Add PUI.examples.grid_sizing with label/value/editor rows, spanning toolbars and a nested Grid beside a Spacer. Make the generic list example scrollable, and make the Adaptive Grid cookbook editor span a full row at every graphical/terminal breakpoint
        * Add TextEdit cookbook coverage and enable the Web/Pyodide Text page with Html rendering and an explicit Markdown support notice
        * Document backend availability with a colour-coded component matrix; distinguish server-side Web from client-side Pyodide, and document direct TCP and restricted relative Unix-socket reverse tunnels
        * Link HTML references and cookbook demos through GitHub Pages. Install pinned frontend dependencies automatically for web-build and pyodide-build; replace the build alias and update publish, Web launch targets and Pages CI
