Callback Interface

All callback interfaces accept an event object as the first argument. Other args/kwargs will be passed through to the callback function. For example 

def button_cb(event, data):
    print(data)

Button("button").click(button_cb, 1)
will invoke 

button_cb(event, 1)
when the event is emitted.

Event Object

click

  • nothing for now

dblclick

  • .x, .y: double click position

mousedown

  • .x, .y: mouse down position

mouseup

  • .x, .y: mosue up position

mousemove

  • .x, .y: mouse move position

wheel

  • .x, .y: wheel position
  • .x_delta, .y_delta: pixel delta
  • .h_delta, .v_delta: angle delta

input

Triggered when typing in `TextField`
  • .value: text in edit buffer

change

Triggered when editing is finished in `TextField`
  • .value: new value

Application

wx reactive views use the native GUI queue; import PUI and PUIView from PUI.wx. Redraw bursts are coalesced and removed views ignore queued work. Application.quit() is queued on wx and tkinter. TimelineView timers follow reconciled nodes and stop after removal.

Window

maximize/fullscreen constructor flags are initial-only on wx, PySide6, tkinter, and Flet. Use .maximize(enabled=True) or .fullscreen(enabled=True) for live changes; False clears the state. Later declarations preserve user window state. wx supports application icons, keypress events, and close/quit accelerators.

flet and textual backends only support single window

Scroll

wx scrollX/scrollY use logical-pixel start offsets for positive values and end offsets for negative values. Scroll.END is negative zero. wx follows content growth at the end and preserves manual positions. Axis options: None (as needed), True (always), False (disabled). Tk Scroll source owns its outer container and filters wheel events locally; native resize/end-following checks are pending. Flet uses native async scroll_to and END auto_scroll; live client checks remain pending.

Scrollable container
Example

    with VBox():

Canvas

Flet 1.x uses native Text/Path/Rect/Oval, including cubic paths and rotated text. Image(path) sends native image bytes; ComboBox uses Dropdown with distinct item values. Canvas image crop/resources, pointer events, and text height clipping remain pending.

wx includes ImageResource.load/crop/scale, loadImage/drawImage source rectangles and opacity, cubic paths, enter/leave, and wheel modifiers. Source image opacity is preserved; native wheel pixel deltas are zero when unavailable. Queued paints after removal are ignored. Tk Canvas source adds native polygon/rectangle/ellipse and text size/color/rotation/anchors; cubic paths, images, and text height clipping are incomplete.

Example 

def painter(canvas):
    canvas.drawText(x, y, text, w=None, h=None, size=12, color=None, rotate=0, anchor=Anchor.LEFT_TOP)
    canvas.drawLine(x1, y1, x2, y2, color=0xFF0000, width=1)
    canvas.drawPolyline([x1, y2, ..., xn, yn], color=0xFF0000, width=1)
    canvas.drawCubicBezier(start, control1, control2, end, color=0xFF0000, width=1)
    canvas.drawRect(x1, y1, x2, y2, fill=0xFF0000, stroke=0x00FF00, width=1)
    canvas.drawShapely(shape, fill=0xFF0000, stroke=0x00FF00, width=1)

Canvas(painter)

drawCubicBezier() is available on PySide6, wx, and Flet. start, control1, control2, and end are (x, y) coordinate pairs defining a cubic Bézier curve.
